
# 🏍️ Primrose Motorcycles - Workshop Management App

Stop using paper jobcards. Manage the whole workshop from one app - Jobcards, Stock, Checklists, Quotes & Invoices.

Built for small motorcycle workshops / mechanics.

### ✨ Key Features

**🧾 Jobcards**
- Create a job with customer, bike model, plate, problem description & status
- Add signature directly on the jobcard with Signature Pad
- Open any jobcard anytime to update it

**📄 PDF Documents - From One Jobcard**
- Generate **Workshop Requisition PDF**
- Generate **Quote PDF**
- Generate **Invoice PDF**
- No re-typing - all PDFs come from the same jobcard

**📋 Smart Checklist**
- Full pre-service checklist: tyres, brakes, oil, lights & more
- If any item is `Not OK`, app shows warning: **"Needs Service" / "Fix Now"**
- Mechanic can't miss a safety issue

**📦 Smart Stock**
- Create stock once e.g. Spark Plug - Part No. 7HS
- Add a part to a jobcard -> stock count **automatically deducts**
- Add stock -> count increases. Remove stock -> count updates
- Always know what's in stock, no more guessing

### 🛠️ Tech Stack
- **Language / UI:** Kotlin, Jetpack Compose, Material 3
- **Architecture:** MVVM, Hilt for Dependency Injection, Coroutines
- **Local DB:** Room
- **Backend:** Firebase Auth, Firestore, Firebase Storage
- **PDF Generation:** Android PDF API
- **Signature:** Signature Pad / Canvas
- **Image Loading:** Coil Compose

### 🚀 How To Run
1. Clone the repo: `git clone https://github.com/owenchikom-star/primrose-motorcycles.git`
2. Open in Android Studio
3. Add your `google-services.json` for Firebase
4. Run on Emulator / Physical Device (Android 8.0+)
